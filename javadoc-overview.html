JJRAM Banking System

A small, terminal-only Java banking simulator built as a team project for UMBC. A customer logs in with an ID and PIN, manages three account types (Checking, Savings, Loan), moves money between them, and sees printed statements — all persisted to a single JSON file between runs.

Packages at a glance

  • bank — the Main entry point. Wires every service together and runs the menu loop.
  • bank.model — pure data + behavior: Bank, Customer, Account (with CheckingAccount, SavingsAccount, LoanAccount), Transaction, TransactionType.
  • bank.auth — AuthService handles login, lockout after 3 failed PINs, and logout.
  • bank.service — TransactionService performs deposits, withdrawals, and atomic transfers. OverdraftPolicy decides whether a withdrawal can go through. InterestCalculator walks every account once a month and applies interest.
  • bank.reporting — StatementGenerator prints formatted monthly statements. TransactionHistory supports filtered searches by date, account, type, amount, and keyword.
  • bank.persistence — DataRepository is the single front door to persisted state. JsonStore is the only class that touches bank.json directly.
